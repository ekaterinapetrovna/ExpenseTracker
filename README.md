# ExpenseTracker — приложение для учёта доходов и расходов

## 1. Описание проекта

ExpenseTracker — приложение на языке Python с графическим интерфейсом, разработанное с использованием библиотеки Kivy.

Приложение предназначено для учёта личных финансов, регистрации доходов и расходов, анализа финансовых операций и синхронизации данных с облачной базой Firebase Realtime Database.

## 2. Цель работы

Разработать приложение для учёта доходов и расходов с возможностью визуализации финансовых данных, экспорта операций и облачной синхронизации.

## 3. Реализованные функции

- Добавление доходов и расходов.
- Выбор категории финансовой операции.
- Автоматический расчёт текущего баланса.
- Просмотр истории транзакций.
- Локальное сохранение данных в JSON.
- Визуализация расходов по категориям с помощью круговой диаграммы.
- Сравнение доходов и расходов с помощью столбчатой диаграммы.
- Экспорт финансовых операций в CSV.
- Авторизация пользователей через Firebase Authentication.
- Загрузка транзакций в Firebase Realtime Database.
- Восстановление данных из облачной базы.

## 4. Используемые технологии

- Python — язык программирования.
- Kivy — создание графического интерфейса.
- Matplotlib — построение графиков.
- Requests — взаимодействие с Firebase REST API.
- Firebase Authentication — авторизация пользователей.
- Firebase Realtime Database — облачное хранение данных.
- JSON и CSV — локальное хранение и экспорт данных.

## 5. Установка и запуск

Для запуска приложения необходимо установить Python и создать виртуальное окружение.

Создание виртуального окружения:

```powershell
python -m venv .venv
```

Установка зависимостей:

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

Перед использованием облачной синхронизации необходимо создать собственный проект Firebase, включить Email/Password Authentication, настроить Realtime Database и указать параметры подключения в локальном файле `firebase_config.py`.

Запуск приложения:

```powershell
.\.venv\Scripts\python.exe main.py
```
